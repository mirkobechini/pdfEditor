# 📄 PdfEditor

**Modifica, visualizza e gestisci file PDF — cross-platform, offline-first, open source.**

[![Desktop latest](https://img.shields.io/github/v/release/mirkobechini/pdfEditor?label=desktop&logo=windows)](https://github.com/mirkobechini/pdfEditor/releases)
[![Mobile latest](https://img.shields.io/github/v/release/mirkobechini/pdfEditor?filter=*-mobile&label=mobile&logo=android)](https://github.com/mirkobechini/pdfEditor/releases)

## 🚀 Piattaforme

| 🌐 Web | 🖥️ Desktop | 📱 Mobile |
|--------|------------|-----------|
| Next.js 16 + TailwindCSS | Tauri v2 (Win/Mac/Linux) | Expo + React Native (Android) |

## ✨ Features

`🔍 Viewer` `🔀 Merge` `✂️ Split` `📋 Reorder` `🗑️ Remove pages` `📝 Metadata` `📸 Scanner→PDF` `🌙 Dark mode` `🔐 Auth` `🌐 i18n IT/EN`
